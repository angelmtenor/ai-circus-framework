Who may run what

Each group is a realm role in the user's token. Tick the tools a group may list and run on each MCP server built with the kit; a group that is not ticked sees the server refuse it. This is the security control: the server enforces it on every call, whatever the chat UI shows.

Only realm roles of infra/keycloak/realm-export.json can be groups.

Servers

Every server is one route on the MCP gateway (/mcp/<name>) and one connection in the chat UI. The title and description are what people and models see.

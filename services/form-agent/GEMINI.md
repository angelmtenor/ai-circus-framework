# Gemini CLI Project Preferences

This project uses a split-context architecture for AI agents. You must load the appropriate context files based on the task:

1. **Mandatory Rules (`AGENTS.md`)**: You MUST read and adhere to `AGENTS.md` for every single task. It contains strict security, workflow, and Git mandates.
2. **Coding Standards (`SKILLS.md`)**: If your task involves writing, refactoring, or reviewing Python code, Makefile targets, or tests, you MUST read `SKILLS.md` before generating your response.

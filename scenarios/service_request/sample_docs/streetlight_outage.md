# Streetlight outage

Request type ID: `streetlight_outage`

Use this when a resident reports a broken, flickering, or permanently-off street
light, or a damaged light pole.

## Required information

- Full name, ID type and number, phone, email.
- **Address / location is required** — the street address or nearest cross-street of
  the affected light, so a crew can be dispatched.
- A description of the problem (e.g. "light out since last week", "pole leaning").

## Routing and turnaround

- Routed to: **Public Works — Street Lighting**.
- Typical turnaround: 3 business days for a single-light outage.
- Multiple outages on the same street may be batched into one work order.

# Noise complaint

Request type ID: `noise_complaint`

Use this for ongoing or repeated noise disturbances: construction outside permitted
hours, loud parties, or commercial noise affecting a residential area. Not for a
single emergency in progress — direct urgent situations to the appropriate
emergency line instead.

## Required information

- Full name, ID type and number, phone, email.
- **Address / location is required** — the location where the noise is occurring
  (not necessarily the complainant's own address).
- A description including time(s) of day the noise occurs and how often.

## Routing and turnaround

- Routed to: **Code Enforcement**.
- Typical turnaround: an inspector follow-up within 5 business days; repeated
  complaints about the same address may be escalated sooner.

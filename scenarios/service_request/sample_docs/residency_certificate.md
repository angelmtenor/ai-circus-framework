# Residency certificate

Request type ID: `residency_certificate`

Use this when a resident needs an official certificate confirming their registered
address — commonly required for school enrollment, bank applications, or other
administrative processes.

## Required information

- Full name, ID type and number, phone, email.
- No separate address/location field is required — the address to certify should
  be stated in the description if it differs from the applicant's registered
  address on file.

## Routing and turnaround

- Routed to: **Civil Registry Office**.
- Typical turnaround: 3 business days.
- The certificate is issued only if the applicant already has a registered address
  on file (see `address_registration` otherwise).

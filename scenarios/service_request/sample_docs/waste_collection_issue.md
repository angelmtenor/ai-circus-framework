# Waste collection issue

Request type ID: `waste_collection_issue`

Use this for a missed trash/recycling pickup, an overflowing public bin, or illegal
dumping/an uncollected pile of waste on public land.

## Required information

- Full name, ID type and number, phone, email.
- **Address / location is required** — the property address (for a missed pickup)
  or the location of the dumping/overflow.
- A description including the collection date missed, or when the dumping was
  noticed.

## Routing and turnaround

- Routed to: **Sanitation Department**.
- Typical turnaround: next scheduled collection day for a missed pickup; up to 5
  business days for illegal dumping cleanup.

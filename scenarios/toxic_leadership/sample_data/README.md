# toxic_leadership sample data

`toxic_leadership.csv` — 4,000 anonymised Glassdoor reviews written by software, data
and AI engineers, generated by `scripts/prepare_toxic_leadership_dataset.py`.

**Source:** "Glassdoor Job Reviews" by David Gauthier, Kaggle —
<https://www.kaggle.com/datasets/davidgauthier/glassdoor-job-reviews> — licensed
**CC BY-SA 4.0** (<https://creativecommons.org/licenses/by-sa/4.0/>). The raw file is
fetched from a pinned Hugging Face mirror and verified against the reviewed SHA-256
before use; it is not stored in this repository.

**This CSV is an adaptation** and is shared under the same licence, **CC BY-SA 4.0**
(the repository's code licence does not apply to it). Changes made:

- kept engineering job titles only, grouped into five job families;
- dropped the employer column (replaced by a coarse sector), the overall rating, CEO
  approval, recommendation, outlook, culture, career, diversity and senior-management
  ratings (the last one becomes the binary `BadLeadership` target);
- joined each review's headline and cons into `Review`, normalised whitespace, cut it at
  1,000 characters, and masked employer names, public executives and HQ towns as
  `[company]` / `[name]`; removed e-mails and URLs;
- dropped duplicate and mostly non-English reviews; drew a stratified 4,000-review sample
  with a fixed seed.

Reviews are anonymous opinions published on Glassdoor, not verified facts about any
organisation or person.
